1. Accounts — tài khoản user

Prefix: /api/accounts/
MethodEndpointChức năng
POST/api/accounts/register/Đăng ký user customer/provider
POST/api/accounts/logout/Logout, xóa access/refresh token
GET/api/accounts/me/Lấy thông tin user hiện tại
PATCH/api/accounts/me/Cập nhật profile user hiện tại
POST/api/accounts/me/change-password/Đổi mật khẩu
POST/api/accounts/cloudinary/sign/Tạo chữ ký upload Cloudinary

2. Providers Admin — admin duyệt provider

Prefix: /api/providers/. Dùng cho admin xem provider pending, duyệt/không duyệt provider.
MethodEndpointChức năng
GET/api/providers/pending/Admin lấy danh sách provider chưa duyệt
PATCH/api/providers/{provider_id}/verification/Admin duyệt/từ chối provider (is_approved, is_verified)

3. Provider Dashboard / Stats

Prefix: /api/provider/. Dùng cho provider/admin xem thống kê doanh thu, booking, service.
MethodEndpointChức năng
GET/api/provider/stats/revenue/Xem thống kê doanh thu tổng quan. Query: period, service_type, service_id
GET/api/provider/stats/services/{service_id}/Xem thống kê 1 service
GET/api/provider/stats/services/{service_id}/stats/Alias cũ cho thống kê 1 service

6. Bookings — đặt dịch vụ

Role: admin thấy tất cả; approved provider thấy booking service của mình; customer thấy booking của chính mình.
MethodEndpointChức năng
GET/api/bookings/Danh sách booking theo role. Filters: booking_status, service, service_type, from_date, to_date
POST/api/bookings/Customer/admin tạo booking
GET/api/bookings/{id}/Chi tiết booking
POST/api/bookings/{id}/cancel/Customer/admin hủy booking
POST/api/bookings/{id}/complete/Provider owner/admin hoàn tất booking
POST/api/bookings/{id}/refund/Admin refund booking

7. Payments — thanh toán

POST/api/payments/Tạo payment cho booking
GET/api/payments/{id}/Chi tiết payment
POST/api/payments/{id}/static-qr-confirmation/Admin xác nhận thanh toán Static QR
POST/api/payments/{id}/confirm_static_qr_payment/Alias cũ
POST/api/payments/{id}/cancel/User hủy payment Static QR còn active

9. Endpoint theo vai trò

Public

  • Register
  • Cloudinary sign
  • Categories, banners
  • Tour/hotel/transport list + detail
  • Tour comments GET
  • Countries/cities

Customer

  • Wishlist
  • Booking create/list/detail own
  • Payment create/list/detail own
  • Cancel own booking/payment
  • Add comment

Provider

  • Create/update own services
  • View provider bookings/payments
  • Complete booking
  • View /api/provider/stats/...

Admin

  • Provider pending/verification
  • Category/banner management
  • All bookings/payments
  • Refund booking
  • Confirm Static QR payment
