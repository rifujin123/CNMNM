Tổng quan React Context + ví dụ từ dự án của bạn

Tài liệu này giải thích React Context theo hướng thực hành: Context là gì, setup ra sao, dùng trong screen như thế nào, skeleton code chuẩn, và ví dụ thật lấy từ dự án TravelBookingSystem.

File tham chiếu trong dự án: context/AuthContext.js, context/WishlistContext.js, App.js, src/screens/HomeScreen.js

1. React Context là gì?

React Context là cơ chế chia sẻ dữ liệu cho nhiều component mà không cần truyền props qua quá nhiều tầng.

App └── HomeScreen └── ItemSection └── ItemCard

Nếu ItemCard cần biết user đã login chưa, cách truyền props từ trên xuống từng tầng sẽ rất dài. Context giúp bạn đặt dữ liệu ở tầng cao, rồi component con lấy trực tiếp bằng hook.

2. Khi nào nên dùng Context?

Nên dùng

  • Auth: token, user, role
  • Theme: dark/light mode
  • Ngôn ngữ
  • Wishlist, cart
  • Notification count
  • App settings dùng nhiều nơi

Không nên dùng

  • State chỉ dùng trong 1 screen
  • Input text tạm thời
  • Modal open/close cục bộ
  • Form state ngắn hạn

3. 4 phần chuẩn của 1 Context

  1. Tạo Context bằng createContext()
  2. Tạo Provider để chứa state chung
  3. Truyền value qua <Context.Provider value={...}>
  4. Tạo custom hook để screen/component dùng dễ hơn
const XxxContext = createContext(null);

export function XxxProvider({ children }) {
  const value = { ... };

  return (
    <XxxContext.Provider value={value}>
      {children}
    </XxxContext.Provider>
  );
}

export function useXxx() {
  const context = useContext(XxxContext);

  if (!context) {
    throw new Error("useXxx must be used inside <XxxProvider>");
  }

  return context;
}

4. Cách setup 1 Context mới

Bước 1: Tạo file context

context/ThemeContext.js

Bước 2: Viết Provider + Hook

import { createContext, useContext, useState } from "react";

const ThemeContext = createContext(null);

export function ThemeProvider({ children }) {
  const [theme, setTheme] = useState("light");

  const toggleTheme = () => {
    setTheme((current) => (current === "light" ? "dark" : "light"));
  };

  const value = {
    theme,
    toggleTheme,
  };

  return (
    <ThemeContext.Provider value={value}>
      {children}
    </ThemeContext.Provider>
  );
}

export function useTheme() {
  const context = useContext(ThemeContext);

  if (!context) {
    throw new Error("useTheme must be used inside <ThemeProvider>");
  }

  return context;
}

Bước 3: Bọc App bằng Provider

import { ThemeProvider } from "./context/ThemeContext";

    </ThemeProvider>

}

8. Phân tích AuthContext của dự án

Code thật rút gọn

const AuthContext = createContext(null);

export function AuthProvider({ children }) {
  const [token, setToken] = useState(null);
  const [user, setUser] = useState(null);
  const [role, setRole] = useState("guest");
  const [authLoading, setAuthLoading] = useState(true);

  const isLoggedIn = Boolean(token && user);

  useEffect(() => {
    bootstrapAuth();
  }, []);

  const bootstrapAuth = async () => {
    try {
      const [storedToken, storedUser] = await Promise.all([
        AsyncStorage.getItem(AUTH_ACCESS_TOKEN_KEY),
        AsyncStorage.getItem(AUTH_USER_KEY),
      ]);

      if (storedToken && storedUser) {
        const userData = JSON.parse(storedUser);
        setToken(storedToken);
        setUser(userData);
        setRole(getUserRole(userData));
      }
    } finally {
      setAuthLoading(false);
    }
  };

  const setAuthData = async ({ accessToken, userInfo }) => {
    setToken(accessToken);
    setUser(userInfo);
    setRole(getUserRole(userInfo));

    await AsyncStorage.setItem(AUTH_ACCESS_TOKEN_KEY, accessToken);
    await AsyncStorage.setItem(AUTH_USER_KEY, JSON.stringify(userInfo));
  };

  const clearAuth = async () => {
    setToken(null);
    setUser(null);
    setRole("guest");
    await AsyncStorage.removeItem(AUTH_ACCESS_TOKEN_KEY);
    await AsyncStorage.removeItem(AUTH_USER_KEY);
  };

  const value = {
    token,
    user,
    role,
    isLoggedIn,
    authLoading,
    setAuthLoading,
    setAuthData,
    clearAuth,
  };

  return <AuthContext.Provider value={value}>{children}</AuthContext.Provider>;
}

export function useAuth() {
  const context = useContext(AuthContext);
  if (!context) {
    throw new Error("useAuth must be used inside <AuthProvider>");
  }
  return context;
}

Luồng hoạt động của AuthContext

App mở → AuthProvider mount → useEffect chạy bootstrapAuth() → đọc token + user từ AsyncStorage → nếu có dữ liệu: setToken, setUser, setRole → authLoading = false → screen dùng useAuth() lấy dữ liệu

AuthContext dùng để làm gì?

  • Biết user đã đăng nhập chưa
  • Lấy thông tin user ở nhiều screen
  • Phân biệt role: guest / provider / user
  • Điều hướng màn hình theo trạng thái đăng nhập
  • Cho các context khác dùng token nếu cần

9. AuthContext được dùng ở đâu?

Ví dụ thật từ App.js

function RootNavigator() {
  const { authLoading, isLoggedIn, role } = useAuth();

  if (authLoading) {
    return (
      <View style={styles.splash}>
        <ActivityIndicator size="large" color="#2563EB" />
      </View>
    );
  }

  return (
    <NavigationContainer>
      <Stack.Navigator screenOptions={{ headerShown: false }}>
        {!isLoggedIn ? (
          <>
            <Stack.Screen name="MainTabs" component={MyTabs} />
            <Stack.Screen name="Login" component={LoginScreen} />
          </>
        ) : role === "provider" ? (
          <>
            <Stack.Screen name="ProviderTabs" component={ProviderTabs} />
          </>
        ) : (
          <>
            <Stack.Screen name="MainTabs" component={MyTabs} />
          </>
        )}
      </Stack.Navigator>
    </NavigationContainer>
  );
}

Ở đây useAuth() quyết định app sẽ hiển thị luồng nào:

  • authLoading → chờ đọc dữ liệu đăng nhập
  • !isLoggedIn → hiện flow chưa đăng nhập
  • role === "provider" → hiện flow provider
  • còn lại → flow user thường

Ví dụ thật từ HomeScreen.js

const { token, user } = useAuth();

Dùng để:

<AppHeader
  title={`Hello, ${user?.first_name?.trim() || user?.username || "Guest"}`}
/>

10. Phân tích WishlistContext của dự án

Code thật rút gọn

const WishlistContext = createContext(null);

export function WishlistProvider({ children }) {
  const { token } = useAuth();
  const [wishlistIds, setWishlistIds] = useState([]);
  const [isLoading, setIsLoading] = useState(false);
  const [error, setError] = useState(null);

  useEffect(() => {
    if (token) {
      loadWishlist();
    } else {
      setWishlistIds([]);
      AsyncStorage.removeItem(WISHLIST_STORAGE_KEY);
    }
  }, [token]);

  const loadWishlist = async () => {
    try {
      setIsLoading(true);
      setError(null);
      const ids = await fetchWishlist({ token });
      setWishlistIds(ids);
      await AsyncStorage.setItem(WISHLIST_STORAGE_KEY, JSON.stringify(ids));
    } catch (err) {
      setError(err.message);
      const cached = await AsyncStorage.getItem(WISHLIST_STORAGE_KEY);
      if (cached) {
        setWishlistIds(JSON.parse(cached));
      }
    } finally {
      setIsLoading(false);
    }
  };

  const addToWishlist = async (tourId) => {
    await addWishlist({ token, tourId });
    const newIds = [...wishlistIds, String(tourId)];
    setWishlistIds(newIds);
    await AsyncStorage.setItem(WISHLIST_STORAGE_KEY, JSON.stringify(newIds));
  };

  const removeFromWishlist = async (tourId) => {
    await removeWishlist({ token, tourId });
    const newIds = wishlistIds.filter((id) => String(id) !== String(tourId));
    setWishlistIds(newIds);
    await AsyncStorage.setItem(WISHLIST_STORAGE_KEY, JSON.stringify(newIds));
  };

  const isWishlisted = (tourId) => {
    return wishlistIds.some((id) => String(id) === String(tourId));
  };

  const toggleWishlist = async (item) => {
    const tourId = item?.id;

    if (isWishlisted(tourId)) {
      await removeFromWishlist(tourId);
    } else {
      await addToWishlist(tourId);
    }
  };

  const value = {
    wishlistIds,
    isLoading,
    error,
    isWishlisted,
    toggleWishlist,
    addToWishlist,
    removeFromWishlist,
    refetch: loadWishlist,
  };

  return (
    <WishlistContext.Provider value={value}>
      {children}
    </WishlistContext.Provider>
  );
}

export function useWishlist() {
  const context = useContext(WishlistContext);
  if (!context) {
    throw new Error("useWishlist must be used inside <WishlistProvider>");
  }
  return context;
}

Luồng hoạt động của WishlistContext

WishlistProvider mount → dùng useAuth() lấy token → token đổi → nếu có token: gọi loadWishlist() → nếu không có token: clear wishlist local → screen gọi useWishlist() → có thể check tim, thêm tim, xoá tim, refetch
Điểm quan trọng:
WishlistContext phụ thuộc AuthContext vì cần token để gọi API.

13. Ví dụ: tự tạo 1 context mới trong tương lai

Ví dụ NotificationContext

import { createContext, useContext, useState } from "react";

const NotificationContext = createContext(null);

export function NotificationProvider({ children }) {
  const [count, setCount] = useState(0);

  const increase = () => setCount((prev) => prev + 1);
  const reset = () => setCount(0);

  const value = {
    count,
    increase,
    reset,
  };

  return (
    <NotificationContext.Provider value={value}>
      {children}
    </NotificationContext.Provider>
  );
}

export function useNotification() {
  const context = useContext(NotificationContext);

  if (!context) {
    throw new Error("useNotification must be used inside <NotificationProvider>");
  }

  return context;
}

Bọc vào App

export default function App() {
  return (
    <AuthProvider>
      <WishlistProvider>
        <NotificationProvider>
          <RootNavigator />
        </NotificationProvider>
      </WishlistProvider>
    </AuthProvider>
  );
}

14. Checklist tự tạo Context

  • Tạo file mới trong thư mục context
  • createContext(null)
  • Tạo Provider chứa state và function
  • Truyền value vào Provider
  • Tạo custom hook useXxx()
  • Bọc Provider trong App.js
  • Gọi hook trong screen/component
  • Nếu cần data bền vững, kết hợp AsyncStorage
  • Nếu cần gọi API, để function async trong Provider
